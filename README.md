# Hotel Management System

## Project Overview

The Hotel Management System is a Java-based application developed to manage basic hotel operations. It provides a role-based system where different users can access specific features based on their responsibilities.

The project demonstrates the practical use of Java programming and object-oriented programming concepts in developing a management application.

## Features

- **Admin:** Manage overall hotel operations and system activities.
- **Manager:** Handle hotel management tasks.
- **Staff:** Access staff-related functions.
- **Customer:** Access customer-related services.
- Role-based login and access control.
- Member management.
- Organized management of hotel operations.

## User Roles

The system includes four main user roles:

1. Admin
2. Manager
3. Staff
4. Customer

Each role has different responsibilities and access permissions.

## How to Run

1. Download or clone this repository.
2. Open the project in IntelliJ IDEA, Eclipse, or another Java IDE.
3. Make sure Java JDK is installed.
4. Locate the main Java class.
5. Run the main class to start the application.
